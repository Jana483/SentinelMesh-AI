# SentinelMesh AI

**Keeping enterprise communication alive, secure, and uninterrupted during infrastructure failures.**

SentinelMesh AI is a responsive prototype dashboard for an autonomous communication continuity and cyber resilience platform. It brings service health, resilience signals, incident status, and response playbooks into one operations view.

## Run locally

Open `index.html` in a browser. The prototype uses plain HTML, CSS, and JavaScript; no build step or dependency installation is required.

## Demo behavior

All telemetry and operational figures shown in the dashboard are illustrative sample data. No enterprise services or infrastructure are connected. The recovery drill only displays a demo confirmation, and report export downloads a text snapshot of the sample metrics.
